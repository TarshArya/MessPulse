# MessPulse – Smart Mess Feedback & Analytics System

MessPulse is a web-based platform designed to collect and analyze hostel mess feedback in real-time, helping improve food quality and dining experience through data-driven insights.

## 🚀 Features
- 📱 QR-based meal tracking system for each user  
- ⏱️ Automatic timestamp logging when meals are served  
- ⭐ Real-time rating and feedback system  
- 📊 Admin dashboard for analytics and insights  
- 📅 Weekly menu management by admin  
- 🔄 Daily menu auto-update system  

## 🛠️ Tech Stack
- Python (Flask)  
- SQLite  
- HTML, CSS, JavaScript  
- Jinja Templates  

## 💡 Problem Statement
Traditional mess feedback systems are inefficient and lack real-time insights. MessPulse solves this by enabling instant feedback collection and structured data analysis to improve decision-making.
